# 轨映 Orbit Frame 全流程 Skill 使用说明书

版本：2026-10-10。这个包让 Codex、Claude Code 或其他能读取 Skill/调用本地工具的 Agent，直接使用你的 Orbit Frame 项目。包括文生视频、图生视频、首尾帧视频、外接 gpt-image-2.5 生图和编辑、画布镜头与清单恢复。

## 安装

解压后整个 `orbit-frame` 文件夹就是 Skill。它不包含完整项目、Node 依赖、账号登录或密钥；需要本轮修复后的 Orbit Frame 源码和运行中的本机网关。

- Codex：把文件夹放在 `~/.codex/skills/orbit-frame`，启动或刷新会话后用 `$orbit-frame` 调用。
- Claude Code：把文件夹放在项目 `.claude/skills/orbit-frame` 或用户 `~/.claude/skills/orbit-frame`，用 `/orbit-frame` 调用；也可以先让 Agent 读取 SKILL.md。[官方 Skill 安装说明](https://code.claude.com/docs/en/skills)
- 其他 Agent：让它读取 SKILL.md；支持 MCP 的客户端按下方配置 stdio 服务器，也可以直接执行 CLI。

本机已安装 Codex 副本。安装 Skill 与接入 MCP 是两件事：Skill 告诉 Agent 怎么做，MCP 提供真实可调用工具。

## 告诉 Agent 项目在哪

进入完整项目目录执行最方便；从其他目录启动可设置 ORBIT_FRAME_PROJECT_DIR，或每次明确传 --project：

```sh
node /Skill目录/scripts/orbit.mjs --project /完整项目路径 health
node /Skill目录/scripts/orbit.mjs --project /完整项目路径 video check
node /Skill目录/scripts/orbit.mjs --project /完整项目路径 image providers
```

health 只查网关，video check 查客户端和登录，image providers 查外接图片提供商。不要把 Skill 文件夹误当成项目目录。助手委托的相对路径以项目为准，建议图片、输出和清单都填写完整路径。

## 给 Agent 的直接指令

```text
使用 $orbit-frame。项目在 /完整项目路径。
用 /完整路径/首帧.png 和 /完整路径/尾帧.png 生成视频：
提示词是“从清晨平滑过渡到星夜，保持人物、服装与构图”。
使用 Seedance 2.5、5 秒、9:16。
优先 MCP，不能用时使用 CLI；保存原任务编号，超时查询原任务，
完成后下载核验的云盘原片，并返回本地视频文件和预览链接。
```

单图只提供首帧；文生视频只提供提示词。直接生成用 [CLI 示例](references/cli.md) 或 [MCP 示例](references/mcp.md)，不必操作画布。

需要同时在画布显示，就让 Agent 先 compose_video_scene 准备提示词、首尾帧和连线，再按返回的 canvas/card 生成。只要求“准备镜头”时不会生成媒体。

## 外接生图已包含

服务地址：`http://127.0.0.1:63451/v1`；请求别名：`gpt-image-2.5`；provider：`openai-compatible`。密钥不在包里，你这台电脑可沿用已经保存的生图设置。

换电脑或换配置时，使用生图设置页，或复制 assets/image-provider.env.example 到本机私有位置，填真实密钥再由 configure-images 保存。具体步骤见 [本机设置说明](references/operations.md)。不用把生图密钥填成 LOCAL_API_KEY。

```text
使用 $orbit-frame 和已配置的 openai-compatible / gpt-image-2.5。
严格使用 /完整路径/首帧.png 作为参考图，保持人物和构图，
只把窗外蓝光编辑成紫色星夜，保存尾帧。
再用原首帧和新尾帧生成一条 5 秒、9:16、Seedance 2.5 视频。
本次最多允许两次新媒体生成，保留图片父子关系和原任务编号。
```

这个流程需要一次参考图编辑和一次视频生成。模板 assets/reference-to-video.manifest.json 可让 Agent 建立依赖，不用人工找图或连线；现成双图用 existing-frames.manifest.json，只需一条视频。

## 接入 MCP

```sh
node /Skill目录/scripts/orbit.mjs --project /完整项目路径 mcp-config
```

把输出的 MCP JSON 合并到客户端配置，重连后应看到 13 个工具。不向配置或工具参数加入密钥；如果客户端不是 JSON 配置，使用相同 command/args 填它自己的设置。详见 [MCP 接入与工具表](references/mcp.md)；Claude Code 可使用项目 `.mcp.json`，按 [官方 MCP 配置说明](https://code.claude.com/docs/en/mcp) 处理首次信任提示。

网关型号参数不等于账号实际权限；上游有时只能证明 requested_only。外接图片同步服务暂不支持上游任务查询或取消，超时保持 unknown。视频仅交付验证过的云盘原片，但不保证所有未来云盘视频无水印，包内没有去水印功能。参考图与成片仍要实际比对。

包内 `scripts/self-test.mjs` 可在 Node 下运行非生成自检；它使用临时模拟项目，不消耗上游额度。所有示例应先替换路径，实际生成次数由你当次要求决定。
