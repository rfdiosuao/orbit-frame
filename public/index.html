API Key 从哪里获取？

这是你自己配置的网关访问密钥，不需要向豆包申请。打开项目根目录的 .env，找到 LOCAL_API_KEY。

在项目终端运行以下命令可复制当前密钥，然后粘贴到下方：

npm run api:key -- --copy

新部署时请生成随机密钥写入 .env，修改后重启网关。不要使用示例值。

勾选后，密钥会保存在这个浏览器中；不勾选时只在当前页面使用。
