## 重复运行

可直接使用仓库中的 [压测 Skill](../skills/orbit-frame-pressure-test/SKILL.md)，本机副本安装在 `~/.codex/skills/orbit-frame-pressure-test`，名称 `$orbit-frame-pressure-test`。

只读基线：

```sh
node scripts/orbit-frame-stress.mjs --mode read-only --requests 150 --concurrency 15 --output data/stress/new-run/read-load
```

真实 MCP 计划需要用户授权生成后再运行。`request.json` 在发送前保存编号，同一个输出目录只允许相同参数，重复运行恢复原请求。图片与视频 CLI 均支持 `--help`，无需手填 API Key。

## 验收边界

本轮没有做数百条同时生成，也没有验证跨账号、所有图片格式和长时间运行的所有断网组合。Seedance/Seedream 型号仍是请求参数，未获得上游可独立核验的严格型号证明。若原附件无法读取、云盘关系无法核验或交付 ACK 丢失，系统保留任务并明确报错，不把普通视频或重绘图误报为成功。
