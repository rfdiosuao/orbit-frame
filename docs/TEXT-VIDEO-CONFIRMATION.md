# 普通文字视频确认

豆包可能只输出“请确认以下视频生成参数”，没有确认卡片，并把参数摘要轮次标记为 completed。网关识别这种普通文字确认，以及 Seedance 2.5 的“生成前确认 / 是否按以上信息生成”问句，不将它误当作已经生成的视频。

只有模型、时长、比例与本次授权参数完全一致，且没有生成任务、附件或付费提示时，才在同一会话发送一次文字确认。发送前持久化意图，收到 ACK 后保存 generationRunId；保留最初 runId、task_id 和幂等键。结果未知时不会自动重发。

用户已在原会话紧接着发送“确认”时，网关关联该轮次并查询已有结果，不再发送生成请求。后续任意新话题、参数变更或重复摘要不会触发重复确认。

确认成功不等于成片交付：云盘来源与 MP4 的核验继续独立执行。

支持 Markdown 反引号、固定模型注释和 seedance_2.5 内部模型名称。识别等待确认与是否允许自动回答分开处理：参数不匹配或涉及付费时仍显示等待确认，禁止自动回答和视频提取。
