# 提示词与首尾帧操作审查（2026-10-09）

本次使用桌面浏览器实际点击、输入和拖线，检查「文字卡 + 首帧 + 尾帧 → 视频生成 → 成片播放」。

## 发现并修复的问题

- 文字卡只有备注功能，没有输出端口；视频卡自己的提示词仍为空。实际点击生成时提示「请先写视频提示词」，并不会采用文字卡内容。
- 画布保存规则只允许图片作为视频输入，没有提示词连线角色；提交时也只读取视频卡自己的 prompt。
- 缩放或适应画布后，连线可能偏离真实端口。修复为读取画布坐标，并在缩放和滚动时重新绘制。
- 请求已提交或结果不明时，提示词和参数需要保存快照；后续文字编辑或撤销不能改变同一次请求。
- 真实任务出现新的 `confirm_generate` 确认按钮，原规则无法识别。补充本次观察到的确认格式，保留费用、歧义选项与重复确认的拦截。
- 新建视频卡的占位高度低于实际输入表单，可能盖住已有文字卡。按卡片类型增加布局预留高度。

## 修复后的操作方式

1. 添加「文字」卡，输入动作、镜头或首尾画面间的过渡。
2. 点击文字卡的「用这段文字创建视频」，自动建立黄色提示词连线。
3. 在视频卡选择首帧和尾帧，分别建立绿色、紫色连线。
4. 设置时长和比例，点击生成。

已有视频卡可以在「提示词来源」选择文字卡，或将文字卡右侧的 ✎ 拖到视频左侧的 ✎。也可以选择「直接在下方输入」。文字与图片分别接入同一张视频卡。
