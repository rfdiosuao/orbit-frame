## 验收中修复的问题

- 网关默认上游地址与模板不一致，统一为本机 8000 端口。
- 空密钥读取正则会跨行吞掉中文注释，生成无法用于 HTTP 的 Bearer 值；改为只读同一行并拒绝不可用字符，补了留空/引号/无效字符回归测试。
- 网关或上游异常退出时另一个进程可能残留；现在同次启动的进程一起停止，防止下次启动端口被占用。
- macOS 临时目录/路径别名导致部署入口静默不执行；入口按实际文件路径判断，并验证中文空格目录下的 MCP 配置。
- 新机的本地图片服务地址、MCP 路径、压测 Skill 路径与凭据初始化均写入部署教程。

## 仍由新电脑完成的验收

新电脑需安装 Node 和 Doubao.app、登录自己的账户、配置可访问的外接生图服务，再按教程生成一条 5 秒视频并预览、下载。当前验证不包含新媒体生成、客户端重启/登录或真实后台服务安装；不消耗本次生成额度。

外接生图配置有意不迁移，故测试副本显示 `image_provider_available=false`。这与视频主链路检查成功不冲突。安装包不包含实际密钥、登录资料、历史生成文件或第三方客户端安装包。
