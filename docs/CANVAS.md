# 画布：用图片安排视频的开始和结束

首页点击「画布 ↗」，再添加一张视频卡片。

Agent 可以直接调用 MCP `compose_video_scene`，传提示词与本地首尾帧路径，系统自动上传、建卡、连线和排版；再通过 `generate_and_wait({canvas_id, card_id})` 生成并挂回原卡片。`get_canvas` 返回角色与缺失项，不需要读屏或拖线。网页「同步镜头」可读取外部保存的修改。详见 [Agent 工作流](AGENT-WORKFLOW.md)。

1. 点击「选择首帧」：选择画布里的图片、素材库图片，或上传 PNG / JPEG / WebP。这是视频开始的画面。
2. 需要指定结束画面时，再点击「选择尾帧」。只选首帧是图生视频，两张都选是首尾帧模式；不选图片是文生视频。
3. 在视频卡片的「✎ 提示词」里直接输入动作或过渡。也可以添加「文字」卡，在「提示词来源」选择它，或将文字卡右侧的 ✎ 拖到视频左侧的 ✎。文字卡的「用这段文字创建视频」按钮会自动创建并连接视频卡。设置秒数和画面比例，点击「生成视频」。
4. 完成后视频直接出现在卡片中，可以播放、下载，或在创作页打开。

① 首帧采用绿色，② 尾帧采用紫色；连线使用对应颜色和文字。卡片左侧的两个入口也可以拖入图片。选择图片会自动建立连线，不需要手动拖线。

✎ 提示词采用黄色连线，与首帧、尾帧分别接入同一张视频卡。连接后，下方显示实际采用的文字；点击「编辑文字卡」修改来源。切回「直接在下方输入」会保留当前文字。空白文字卡会阻止提交，不会悄悄使用旧提示词。提交时保存提示词快照，修改来源文字不会改变已提交任务或同一次请求的重试内容。

选错图片时点击「更换」，也可移除或「交换首尾帧」。只有尾帧时会提示缺少首帧，并禁止提交。请求已经提交或结果不明时，输入帧锁定；撤销不会改写该任务的输入。

拖卡片标题可移动，拖空白处可平移；点击「适应」找回所有卡片，小窗口也能使用。⌘ 加滚轮缩放，⌘Z 撤销，⇧⌘Z 重做。画布会自动保存；保存失败时暂不允许切换，避免丢失未保存的修改。

两窗口编辑同一画布发生冲突时，本地修改会保留为“冲突恢复”副本，原画布保留另一窗口的修改。刷新后，可通过顶部列表打开对应画布。

视频任务刷新后继续查询原编号。暂时断线的任务会自动重连；需要人工输入或确认结果不明的任务保留记录，可通过「重新查询」或在豆包核对后处理。移除卡片不会取消豆包生成，也不会删除作品文件。

图片任务刷新后会继续等待；图片拥有进程已退出时，当前上游接口无法自动接管生成，请先核对豆包结果，再决定是否重新生成。

网关保存豆包返回的视频文件，没有去水印处理。文件附件与视频卡片可能交付不同版本，有没有可见水印取决于上游返回的文件。
